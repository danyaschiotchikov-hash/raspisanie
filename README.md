# Расписание Петрозаводской консерватории

Неофициальное приложение: каждый день забирает PDF-файлы с расписанием занятий
текущего семестра с [glazunovcons.ru](https://glazunovcons.ru/study/) и показывает их
по группам и преподавателям — на компьютере сеткой недели, на телефоне лентой.

* выбор недели, «Моя группа» открывается по умолчанию;
* поиск преподавателя с подсказками;
* личные занятия с повторением (разово, каждый день, по будням, каждую неделю,
  раз в две недели, каждый месяц; можно удалить одно повторение);
* русский и китайский (中文) интерфейс, названия дисциплин переведены;
* работает без сети (PWA), ставится на главный экран;
* Android-приложение с виджетом «Сегодня / Неделя».

## Как устроено

| Папка / файл | Что это |
|---|---|
| `scraper.py` | находит PDF на сайте консерватории и разбирает таблицы в `site/data/schedule.json` |
| `site/` | сам сайт (публикуется на GitHub Pages) |
| `android/` | Android-приложение: сайт в WebView + виджет на главный экран |
| `.github/workflows/update.yml` | ежедневное обновление расписания, сборка APK, публикация |
| `app.py` | локальный запуск на компьютере (с кнопкой «Обновить с сайта») |

## Публикация на GitHub Pages

1. Отправить репозиторий на GitHub (публичный).
2. **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. **Actions → «Обновление расписания» → Run workflow** (дальше запускается само каждый день в 06:15 МСК).

Сайт появится по адресу `https://<логин>.github.io/<репозиторий>/`,
APK — на том же сайте в карточке «Виджет для Android».

## Виджет на Android

1. Открыть сайт на телефоне → «Скачать APK» → установить
   (Android попросит разрешить установку из браузера).
2. Открыть приложение «Расписание», выбрать группу и нажать «Сделать моей группой».
3. Долгое нажатие на главном экране → «Виджеты» → «Расписание».
   Кнопка на виджете переключает «Сегодня» / «Неделя», стрелка — обновляет.

Приложение подписано постоянным ключом `android/app/release.jks`, поэтому новые версии
ставятся поверх старых. Ключ лежит в открытом репозитории — для личного приложения
это нормально, но не используйте его для чего-то ещё.

## iPhone

Настоящее iOS-приложение требует Mac и платного аккаунта разработчика Apple, поэтому на iPhone:

* **Приложение** — сайт устанавливается на экран «Домой»: Safari → «Поделиться» → «На экран «Домой»».
  Открывается как отдельное приложение и работает без интернета.
* **Виджет** — через бесплатное приложение [Scriptable](https://scriptable.app/). На сайте:
  «Установить на iPhone» → «Скопировать скрипт виджета» (в скрипт подставляются ваша группа,
  язык и личные занятия), в Scriptable «+» → вставить. Затем виджет Scriptable на экран «Домой»,
  Script — «Расписание», Parameter — пусто («Сегодня») или `неделя` (7 дней).
  Шаблон скрипта — `site/ios/widget.js`, проверка без iPhone — `node tools/test_ios_widget.mjs large неделя`.

## Локальный запуск

    pip install -r requirements.txt
    python app.py

или двойной щелчок по «Запустить расписание.bat». Откроется http://localhost:8765/.
